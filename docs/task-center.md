# 虎牙任务中心

支持读取虎牙 13.5.62 和 13.5.63 的福利任务列表，按开关执行已适配的任务并领取奖励。

## 当前范围

| 类型 | 处理方式 |
| --- | --- |
| 普通用户任务、混合任务 | 读取任务名称、进度及领取状态 |
| 已达标普通奖励 | 按原接口领取，服务端确认成功后才记成功 |
| 下载、安装任务 | 跳过，不启动下载器或安装器 |
| 合作 App 验证、独立跳转或激励流程 | 跳过并记录原因，不伪造完成或回流 |
| 玩游戏赚金币、限时活动、浏览 APP 赚金币 | 不读取、不显示、不执行 |
| 注册、充值、购买、交易、邀请、弹幕等操作 | 不自动执行 |
| 骰子任务 | 读取真实任务清单、独立开关；倒计时复核领奖，指定免费虎粮赠送，静默视频奖励 |
| 骰子任务中的付费打赏、金币兑换 | 不显示、不自动执行 |
| 骰子任务中的浏览游戏商城15s | 后台提交已实机确认的任务事件，刷新服务端进度及已领次数 |
| 骰子任务中的添加桌面小组件 | 从模块任务清单移除，不显示、不执行 |
| 骰子任务中的试玩、首页来源等未适配任务 | 从模块任务清单移除，不显示、不执行 |

这版没有实现全部任务的自动完成；不会把未完成任务直接改成已完成，也不会通过清空日志重复领取。

## 设置

进入模块首页 → 虎牙详情。二级页保留粉丝牌打卡、免费虎粮和执行间隔；“骰子任务”“每日赚金币”分别进入独立三级页。

“骰子任务”页提供每日自动投骰子、骰子任务总开关及单项任务开关。骰子任务开关默认关闭，与打卡、免费虎粮和广告开关独立。“每日赚金币”页仅显示整点领金币和饭点领金币补贴。整点金币在服务端确认达标后进入领奖队列。饭点补贴逐项查询餐段，确认已完成且未领取才领奖。

骰子任务中的免费虎粮有独立房间列表，可添加、修改、删除和置顶。按列表优先顺序，每次只送 1 个免费虎粮，收到回执后复核骰子任务进度。每房间数量限制当天最大尝试次数，结果不明也计入上限；未配置房间时不赠送。只有免费库存、道具和最终支付请求均通过校验才发送，不购买或自动付费。

倒计时任务按服务端剩余时间等待，再重新查询任务。视频任务使用服务端返回的广告任务 ID 和原生领奖回调，不打开广告页面；仅提交回调不视为任务完成，仍需复核服务端进度。接口异常或结果未确认时不重试。

“任务执行间隔”默认 30 秒，可设置为 5–600 秒。任务串行处理，收到上一请求的回执后等待该间隔，再发送下一请求。间隔设置在下轮任务中生效，不保证避免平台安全校验。

每天首次打开虎牙、登录就绪后触发。模块无需自启动；不会为了执行任务打开第三方 App。修改配置后强制停止虎牙再打开；当天已触发的任务不会因此重做。

开启每日自动投骰子后，本轮骰子任务结束时会检查库存，之后空闲时每 15 分钟复查。查到可用骰子便直接投掷，每次收到回执后按任务间隔复核库存，再处理下一颗。开启定向赠送免费虎粮后，首轮检查之后每 30 分钟检查尚未提交赠送的房间，当天已提交的房间不会重复赠送。

三级日志页记录任务读取、等待、请求已发出、成功、失败、已领取、跳过、未执行和结果未确认。请求超时、账号改变或安全验证时停止本轮，不自动重试。
